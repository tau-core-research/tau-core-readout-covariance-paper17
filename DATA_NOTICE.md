# Data Notice

This repository contains a compact synthetic-methodology package derived from
`taucore_readout_covariance_package`.

Included data are synthetic tables and figures only:

- v8 shared-parent stability audit tables;
- v9 matched-filter rejection tables;
- v10 orientation diagnostic tables;
- v11 two-axis classifier tables;
- generated paper figures derived from those compact tables.

No real survey products, private observational data, or empirical endpoint
datasets are included.  The package does not claim real-data validation,
cosmological validation, dark-sector detection, or physical proof of Tau Core.

The synthetic package is useful for protocol design: it shows how a shared
parent signal can be separated from orientation-only structure under controlled
toy conditions.  It must be followed by mock-catalog injection and blind
source-frozen real-data tests before any empirical interpretation is allowed.
