# 05 — Claim Boundaries and Attack Surface

## 1. What this package does not prove

This package does not prove:

\[
\text{Tau Core is true.}
\]

It does not prove:

\[
\text{dark matter is solved.}
\]

It does not prove:

\[
\text{Turok–Bateman proves Tau Core.}
\]

It does not prove:

\[
\text{real lensing/CMB/cosmic-web anomalies are Tau Core signals.}
\]

## 2. What this package supports

It supports the methodological claim:

\[
\boxed{
\text{A shared-parent synthetic signal can be recovered through cross-readout covariance.}
}
\]

It supports:

\[
\boxed{
\text{Tau Core should be tested as a multi-axis diagnostic programme.}
}
\]

It supports:

\[
\boxed{
\text{orientation/morphology is secondary and conditional, not standalone evidence.}
}
\]

## 3. Main attack surface

### 3.1 Parent not yet physically identified

\[
\mathcal{P}_\tau=?
\]

Unknown: field space, algebraic object, geometric configuration space, or something else.

### 3.2 Projectors not yet derived

\[
\Pi_i
\]

are currently modeled, not derived from first principles.

Needed:

\[
\Pi_i
=
\arg\min_{\Pi}
[
\text{negativity}
+
\text{instability}
+
\text{causal violation}
+
\lambda\text{complexity}
].
\]

Or a deeper symmetry principle.

### 3.3 Covariance model may be flexible

The model must be constrained by:

- low parameter count,
- pre-registration,
- surrogate tests,
- out-of-sample testing,
- BIC/AIC penalty.

### 3.4 Residuals may disappear

Better baryonic, survey, or \(\Lambda\)CDM modeling may remove residuals.

If so, the corresponding Tau Core branch weakens.

### 3.5 Synthetic validation is not empirical evidence

Toy fields are necessary for pipeline validation, but not enough for physical claims.

## 4. Safety rule for interpretation

\[
\boxed{
\text{No real-data Tau Core claim before synthetic, mock, and out-of-sample survival.}
}
\]
